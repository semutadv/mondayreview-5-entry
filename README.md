A Monday, reviewed in one line for the make.fun bounty of that name:
one star. It arrived uninvited, ate the weekend's leftovers, and left
a meeting in the calendar as a tip. Management has responded to the
review by scheduling a follow-up, which is also a meeting.

## Running it

`node main.ts` clears the output directory's contents and writes the
review to `/output/entry.txt` as plain UTF-8 text.
